# ElectricityBillCalculator
A responsive web application developed using **Java Servlet, JSP, Bootstrap, and jQuery** to calculate electricity bills based on slab-wise electricity tariff rates.

#  Project Overview
This project calculates the electricity bill according to the number of electricity units consumed by a customer.
The application accepts the number of units from the user, calculates the bill using predefined slab rates, and displays the total amount.The UI is fully responsive and built using Bootstrap.
